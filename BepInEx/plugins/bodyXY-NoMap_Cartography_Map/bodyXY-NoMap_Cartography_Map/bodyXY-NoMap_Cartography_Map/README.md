# No Map Cartography Map 
## by TreacleMiner 📝  
This is a reupload of the original mod by TreacleMiner on Nexusmods:

https://www.nexusmods.com/valheim/mods/2532. 

I have not changed anything and likely won't be updating it myself.

This mod alters the behavior of the Cartography Table on servers where the "No Map" option is enabled.

Interacting with the Cartography Table ("Read map") will now open the Map screen. The map is only visible while standing at the table.
