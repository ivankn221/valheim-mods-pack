># <b># WieldEquipmentWhileSwimming</b>

A simple mod that lets you wield your equipments while swimming/diving or in water. (Configurable)

<br/>

>## ## Installation (manual)

- extract `WieldEquipmentWhileSwimming.dll` file to your `BepInEx\Plugins\` folder

<br/>

>## ## Features

- Lets you wield your equipments while swimming or diving (Configurable).
- Uses serversync
- Configurable through config file or [configuration manager](https://valheim.thunderstore.io/package/Azumatt/Official_BepInEx_ConfigurationManager/)
